# Проєкт: [Ешь-Ешь"]

## Архітектура
Проєкт побудований за принципами Feature-Sliced Design та Component-Based Architecture.

### Основні директорії:
- **`src/assets`** — Статичні ресурси (зображення, шрифти, глобальні стилі).
- **`src/components/ui`** — Перевикористовувані UI-компоненти (кнопки, поля вводу, модалки), які не залежать від бізнес-логіки.
- **`src/features`** — Ізольовані модулі бізнес-логіки (наприклад, `auth`, `cart`).
- **`src/hooks`** — Кастомні React-хуки для повторного використання логіки.
- **`src/pages`** — Компоненти сторінок, які відповідають за маршрутизацію.
- **`src/services`** — Шар роботи з API (налаштування запитів).

### Налаштування
- Vite + React + TypeScript.
- Налаштовано Path Aliases (`@/` замість `../../`).
- Код форматується за допомогою Prettier.
